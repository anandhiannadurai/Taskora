# Taskora

Taskora is a full-stack project management platform built using React, Node.js, Express.js, and PostgreSQL.

## Features

- Authentication (JWT)
- Project Management
- Task Management
- Team Collaboration
- Analytics Dashboard
- Focus Mode
- Responsive UI

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL

Authentication:
- JWT
